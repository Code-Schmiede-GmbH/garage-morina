Anmelden

Zum Bearbeiten braucht es einmalig einen Zugangsschlüssel von GitHub. Der Browser merkt ihn sich danach.

  1. Zugangsschlüssel bei GitHub erstellen → (öffnet GitHub, Felder sind schon ausgefüllt)
  2. Bei Repository access «Only select repositories» wählen und garage-morina auswählen.
  3. Ganz unten auf Generate token klicken und den Schlüssel kopieren.
